# Tumaini Africa — Website

Three self-contained pages (HTML, CSS, and JavaScript each in a single file, no build step required),
all telling one unified story: founded locally in 2014, now primarily focused on mobilizing global
support for the Sudan, Eastern DRC, and wider Sahel/Horn of Africa crises.

- `index.html` — the main site: leads with the crisis, tells the founding story as "how we began,"
  and carries the same narrative through every section (foundation programmes, transparency, giving,
  founder's note, footer)
- `give.html` — the dedicated donation page
- `crisis-response.html` — the full, sourced deep-dive on Sudan / Eastern DRC / Sahel and Tumaini
  Africa's honest expansion roadmap

## Deploying this site

1. Create a new GitHub repository and upload all three files so they sit at the top level of the repo.
2. Go to vercel.com, sign in with GitHub, click **Add New → Project**, select this repository, and click **Deploy**.
3. Your site goes live at a free `https://your-project-name.vercel.app` URL, with `/give.html` and
   `/crisis-response.html` reachable automatically.
4. Every future edit and push automatically redeploys within seconds.

## Keeping the crisis figures accurate

The figures throughout the site are current as of August 2026 and cited in full at the bottom of
crisis-response.html. Revisit the sources every few months and update the numbers so the site
doesn't go stale.
